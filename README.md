# 🚀 Estudos de PyTorch & Deep Learning

Repositório dedicado à minha trilha de estudos práticos em **PyTorch** e fundações de **Deep Learning**, cobrindo desde a manipulação básica de tensores até a implementação de arquiteturas para Iniciação Científica (IC).

---

## 📂 Estrutura do Repositório

| Módulo / Pasta | Descrição do Conteúdo |
| :--- | :--- |
| **Módulo 0: Fundamentos** | Manipulação de tensores, operações básicas, conversões e primeiros passos no ecossistema do PyTorch. |
| **Módulo 1: Teoria & Modelagem** | Teoria de Autograd, grafos computacionais, construção de modelos orientados a objetos (`nn.Module`, `nn.Parameter`), loops de treinamento e modos de inferência (`torch.inference_mode()`). |
| **Iniciação Científica (HyperNN)** | Aplicação prática dos conceitos estudados em arquiteturas de pesquisa (Classificadores baseados em *Hyperboxes*). |

---

## 🛠️ Tecnologias e Ferramentas
* **Python**
* **PyTorch** (`torch`, `torch.nn`)
* **Google Colab**
* **Matplotlib** (Visualização de dados e predições)
